## 🌟 Overview

Tesseract Technologies is a forward-thinking technology company specializing in custom, scalable, and intelligent software systems. ---

## ✨ Features

- 🧊 **Interactive 3D Tesseract**: Custom Three.js 4D wireframe hypercube with interactive mouse parallax and luminous cyan core flare.
- 🎨 **Official Brand Aesthetic**: Electric Neon Cyan (`#00D4FF`), Royal Sapphire Blue (`#087BFF`), and Obsidian Deep Space Black (`#02040A`).
- ⚡ **GSAP ScrollTrigger**: Silky-smooth section reveals, magnetic buttons, and orbit animations.
- 📱 **100% Mobile Responsive**: Dedicated mobile drawer navigation, stacked fluid cards, and optimized touch targets.
- ✉️ **Real Email Dispatch**: Contact form connected to FormSubmit AJAX endpoint for direct inbox delivery.
- 🚀 **Lightning Fast**: Built on Vite with sub-second production builds and minimal footprint.

## 🛠️ Tech Stack

- **Core**: HTML5, Vanilla JavaScript (ES Modules)
- **Styling**: Vanilla CSS (Custom tokens, Grid & Flexbox, Glassmorphism)
- **3D Graphics**: Three.js
- **Animations**: GSAP (GreenSock) & ScrollTrigger
- **Typography**: Orbitron, Space Grotesk, Inter
- **Form Handling**: FormSubmit API (AJAX + fallback)
- **Build Tool**: Vite

## 🚀 Getting Started

### Prerequisites

- [Node.js](https://nodejs.org/) (version 18 or higher recommended)
- `npm` or `yarn` / `pnpm`

### Installation

```bash
# Clone the repository
git clone https://github.com/Farwes-Code/tesseract-website.git

# Navigate to the project directory
cd tesseract-website

# Install dependencies
npm install

# Start local development server
npm run dev
```

Open [http://localhost:5173/](http://localhost:5173/) in your browser to view the site.

### Production Build

```bash
# Build optimized production bundle to /dist
npm run build

# Preview production build locally
npm run preview
```

---

## 🌐 Deployment to Vercel

1. Import this repository into [Vercel](https://vercel.com).
2. Framework Preset will automatically detect **Vite**.
3. Build Command: `npm run build`
4. Output Directory: `dist`
5. Click **Deploy**!
